# Techodite Solutions — Starter Website

This is a starter Next.js project (frontend) with Tailwind CSS styling and a cyber-AI theme.
It includes placeholder pages, components, and generated images for use on your site.

## Quick start

1. Extract the ZIP
2. Install dependencies
   ```bash
   npm install
   ```
3. Run development server
   ```bash
   npm run dev
   ```
4. Open http://localhost:3000

Notes:
- Tailwind is configured; to fully integrate theme utilities you may want to follow Tailwind setup docs.
- This starter focuses on frontend; backend API can be added in `/backend` later.
